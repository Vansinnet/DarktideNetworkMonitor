# DarktideNetworkMonitor

A Darktide Mod Framework HUD that displays connection latency, jitter, range, server region, and optional advanced network information during remote-server sessions.

## Installation

Install DMF, place the `DarktideNetworkMonitor` folder in Darktide's mods directory, and add `DarktideNetworkMonitor` to `mod_load_order.txt`.

## Download

Download `DarktideNetworkMonitor.zip` from the [latest GitHub release](../../releases/latest). Do not use GitHub's source-code archives for installation.
